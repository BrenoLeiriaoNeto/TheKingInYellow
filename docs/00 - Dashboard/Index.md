## 🎯 Pilares de Design
1. **Investigação em Primeiro Lugar:** O combate é letal. A informação é a verdadeira munição.
2. **Sanidade como Recurso:** Ler tomos proibidos concede poder, mas corrói a mente do investigador.
3. **Data-Driven:** O conteúdo principal (perícias, ocupações) vive em arquivos estáticos JSON, não hardcoded.
